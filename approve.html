Approve investor access

This page is for Brains admins. It converts an email into the code the site checks against. No data leaves this page.

  1. Get the signer's email from the Netlify Forms notification (or the Forms tab).
  2. Paste it above → Generate. Copy the code.
  3. Open approved.json on GitHub and add the code to the list, in quotes, comma-separated:
    { "approved": ["code1", "code2"] }
  4. Commit — the site updates in ~1 minute. The investor enters their email on the site and is let in.

To revoke someone, remove their code from approved.json and commit.
